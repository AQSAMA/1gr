Graduation Thesis Editing Instructions

1. Purpose and Scope

This project concerns formatting and reference correction only for a graduation thesis written in Markdown, which will later be converted to Microsoft Word.

Primary Focus

Sections 3 and 4: require the majority of edits.

Sections 1 and 2: already well-written; only minor formatting adjustments may be applied. These sections may also be used as stylistic references when needed.


Explicit Non-Goals (Do NOT Do These)

Do NOT rewrite, paraphrase, summarize, expand, or otherwise modify the main text content.

Do NOT change meaning, terminology, or academic tone.

Do NOT introduce new content or remove existing content, except where explicitly allowed below.



---

2. Allowed Edits (Strictly Limited)

The AI agent is allowed to make only the following types of changes:

1. Formatting changes

Font family

Font size

Bold/regular styling

Paragraph indentation

Line spacing

Page layout consistency

Heading hierarchy



2. Structural formatting

Adding or adjusting headings (without changing text content)

Correcting paragraph breaks

Removing accidental extra spacing

Fixing alignment issues



3. Reference handling

Correcting inaccurate references

Consolidating scattered references

Standardizing in-text citations

Cleaning and organizing the reference list (end references or in-text)

Removing malformed or duplicated references



4. Error cleanup

Removing random symbols

Fixing obvious typographical or formatting artifacts

Correcting Markdown-to-Word incompatibilities (without altering text meaning)





---

3. Typography Rules (Mandatory)

Font Families

English text: Times New Roman

Arabic text: Simplified Arabic


Font Sizes

Main headings: 18 pt, bold

Subheadings: 16 pt, bold

Body text: 14 pt, regular (not bold)



---

4. Page Layout and Printing Requirements

All formatting must comply with the following academic printing standards:

1. Paper size: A4, white only


2. Colored or tinted paper is not allowed


3. Page margins:

3 cm on the binding edge

2 cm on all other edges



4. Line spacing: 1.5


5. Paragraph indentation:

Arabic text: new paragraph begins with a 2 cm shift to the left

English text: new paragraph begins with a 2 cm shift to the right



6. Page numbering:

Number all pages sequentially

Start from the Table of Contents

End at the last page

Page numbers must be placed at the top, on the side farthest from the binding edge





---

5. Equations, Figures, and Tables

1. Number equations, figures, and tables separately for each chapter


2. Table titles:

Placed above the table



3. Figure titles:

Placed below the figure



4. Equation numbering:

Numbers must be enclosed in parentheses

Positioned at a consistent distance from the page edge

Alignment must be uniform across the document





---

6. Workflow Expectations for the AI Agent

Treat the Markdown source as the single source of truth

Ensure changes remain compatible with Word conversion

Prefer consistency over creativity

When uncertain, do nothing rather than modifying content

Always preserve the original academic intent



---

7. Priority Order

1. Reference correction and consolidation


2. Formatting compliance (fonts, sizes, spacing)


3. Structural consistency (headings, numbering, layout)


4. Minor cleanup (symbols, artifacts)


5. I will use Git to track changes




---

Critical Reminder:
This task is not content editing.
It is formatting, structure, and reference normalization only.
